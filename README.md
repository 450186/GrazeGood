# GrazeGood

GrazeGood is a full-stack sustainability and nutrition mobile application developed using React Native, Node.js, Express, and MongoDB.

The application allows users to scan product barcodes and instantly receive nutritional information alongside a custom environmental impact score, helping consumers make more informed and sustainable purchasing decisions.

## Features

* Barcode scanning using the device camera
* Product information retrieval through external APIs
* Custom environmental impact scoring system
* Nutritional breakdown and product analysis
* User registration and authentication
* Save products for later review
* Premium membership system
* Daily scan credit system for free users
* Product of the Week recommendations
* Cloud database storage using MongoDB

## Why I Built This Project

GrazeGood was developed as part of a university group project with the goal of encouraging more sustainable consumer choices.

Many food products provide nutritional information but little visibility into their wider environmental impact. GrazeGood combines nutritional data with environmental factors such as ingredients, processing methods, packaging and product origin to provide users with a simple sustainability score.

The project allowed me to gain experience developing a complete full-stack application, integrating external APIs, managing cloud databases, implementing authentication systems and deploying production-ready software.
